# 客服负责渠道配置 · 交互原型

双击 `index.html` 可离线使用，无外部依赖。组织结构、域账号及渠道均为虚构示例，保存仅写入当前浏览器本地存储，不影响真实后台。

已实现：按人员搜索与选择、组织收起展开、渠道搜索与多选、全选当前结果、仅看已选、保存与取消、未保存切换的三种处理、解除全部绑定确认、刷新后保留配置。

项目／大区／版本沿用上游上下文，此页面不重复选择。当前示例固定在一个虚构版本，正式接入时必须按实际上下文隔离绑定。新增渠道不自动授权。

正式接入需要组织结构与域账号接口、当前版本渠道接口、绑定读写接口及管理入口权限校验。报表字段展示仍由 VipReportExtendedField 配置，真实列表、编辑、导出和后端权限校验不在本静态原型中实现。

`verify.cjs` 是本机 Playwright 交互验证脚本，使用独立浏览器上下文，不访问用户浏览器资料；`preview-desktop.png` 和 `preview-mobile.png` 为验证截图。
