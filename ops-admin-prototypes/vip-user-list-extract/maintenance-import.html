导入前必读：

  1. 一次导入一种维护类型，一行对应一次维护记录；角色ID用于唯一关联玩家。
  2. 必填字段须补齐；操作时间、操作人填写历史实际值，不使用当前账号或时间替代。
  3. 文件内重复、未知角色或字段错误会导致整批校验失败，请修正后重新上传。
  4. 与已有记录重复时，可取消全部导入或跳过重复行，不覆盖原记录。
  5. 导入成功后进入待审核，并同步到玩家维护记录。
  6. 支持单工作表 .xlsx；角色ID按文本填写，操作时间格式为 YYYY-MM-DD HH:mm:ss。
  7. 每次导入前请重新下载最新模板，避免配置变化导致校验失败。
